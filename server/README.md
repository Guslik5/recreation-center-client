# 🤖 Telegram-бот и сервер уведомлений базы отдыха «БАРецкий»

Сервер на **Node.js (Express.js)** для онлайн-модерации отзывов и мгновенных уведомлений о заявках на бронирование домиков и бани.

---

## 🚀 Возможности
1. **Модерация отзывов с сайта в Telegram:**
   - При отправке гостем отзыва через модалку на сайте, администратору в Telegram мгновенно приходит сообщение с именем гостя, домиком, оценкой и текстом отзыва.
   - Под сообщением расположены 2 интерактивные кнопки:
     - `[✅ Опубликовать на сайте]` — переводит статус отзыва в `approved` в Firestore, и он сразу же появляется в слайдере отзывов на сайте!
     - `[❌ Удалить]` — удаляет отзыв из базы данных.
2. **Уведомления о бронировании:**
   - При оформлении заявки на бронь бот присылает карточку с выбранным домом, датами заезда/выезда, числом гостей, именем и пожеланиями.
   - Кнопка `[📞 Позвонить]` для звонка гостю в 1 клик с телефона.
   - Кнопка `[💬 WhatsApp]` для мгновенного перехода в чат с гостем.

---

## 🛠 Настройка и запуск

### 1. Создание бота в Telegram:
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Укажите название (например: `База отдыха БАРецкий — Ассистент`) и юзернейм бота (например: `BaretskyBookingBot`).
3. Скопируйте полученный **токен бота** (например: `7123456789:AAH...`).

### 2. Получение ID чата администратора:
1. Запустите созданного бота (нажмите `/start`).
2. Напишите боту [@userinfobot](https://t.me/userinfobot) или добавьте вашего бота в рабочий чат администраторов.
3. Скопируйте числовой `Id` (например: `123456789` или `-100...` для группы).

### 3. Настройка переменных окружения:
В папке `recreation-center-server` создайте файл `.env`:
```env
PORT=3001
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_ADMIN_CHAT_ID=ваш_chat_id
FIREBASE_PROJECT_ID=baretskiy-7a7ac
```

### 4. Установка зависимостей и локальный запуск:
```bash
npm install
npm run dev
```

### 5. Запуск на сервере через PM2:
```bash
# Установка PM2 (если ещё не установлен)
npm install -g pm2

# Запуск процесса бота
pm2 start ecosystem.config.cjs

# Сохранение автозапуска при перезагрузке сервера
pm2 save
pm2 startup
```
